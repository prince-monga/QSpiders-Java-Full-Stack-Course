**1. Check whether a number is even or odd.**  
Example: `12` → Even  
Example: `7` → Odd  

**2. Compare two numbers and print the greater one.**  
Example: `15` and `8` → `15`  
Example: `-3` and `5` → `5`  

**3. Check whether a year is a leap year or not.**  
Example: `2024` → Leap year  
Example: `2023` → Not a leap year  

**4. Check whether a character is a vowel or consonant.**  
Example: `'a'` → Vowel  
Example: `'z'` → Consonant  

**5. Check if a character is a lowercase alphabet.**  
Example: `'g'` → Lowercase  
Example: `'G'` → Not lowercase  

**6. Check whether a number is greater than 100.**  
Example: `150` → Greater than 100  
Example: `50` → Not greater than 100  

**7. Check if a person is eligible to vote (age >= 18).**  
Example: `20` → Eligible  
Example: `16` → Not eligible  

**8. Print "Pass" or Fail of student if marks are >= 40.**  
Example: `85` → Pass  
Example: `39` → Fail
